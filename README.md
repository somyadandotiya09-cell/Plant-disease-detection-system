# Plant-disease-detection-system
Plant disease detection using deep learning 
🌱 Plant Disease Detection System

1. Project Overview

The Plant Disease Detection System is an AI-based web application that identifies plant diseases using leaf images. It uses Deep Learning and Convolutional Neural Networks (CNN) to analyze images and predict possible plant diseases.

2. Objectives

- Detect plant diseases from leaf images.
- Provide quick disease predictions.
- Support early identification of plant diseases.
- Help farmers improve plant health and crop quality.

3. Technologies Used

- Python
- TensorFlow and Keras
- CNN (Convolutional Neural Network)
- Gradio
- Google Colab
- Google Drive
- GitHub
- OpenCV
- NumPy

4. System Workflow

1. User uploads a plant leaf image.
2. The image is preprocessed.
3. The trained CNN model analyzes the image.
4. The system predicts the disease category.
5. The prediction result is displayed on the web interface.

5. Project Files

- "plant_disease_model.keras" – Trained deep learning model.
- "labels.txt" – Disease class names.
- "app.py" – Application code (if included).
- "requirements.txt" – Required Python libraries.
- "Plant_Disease_Project.ipynb" – Google Colab notebook.

6. Installation

Install the required libraries:

pip install -r requirements.txt

7. How to Run

1. Download the project files.
2. Install the required Python libraries.
3. Load the trained Keras model.
4. Run the application code.
5. Upload a plant leaf image to get a prediction.
